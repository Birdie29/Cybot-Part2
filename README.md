                                    CYBOT CHATBOT PART 2 - # Cybot

DESCRIPTION:

The second part of my chatbot will explore how the user interacts with the bot when it comes to specific topics and if the bot can maintain and reply in a natural conversational manner to the user. The sole purpose of the bot is to educate the user on specific cybersecurity topics and how well it maintains a natural conversational flow.

FEATURES:

-ASCII image and a wav audio
-User input validation statements
-Speech synthesis method
-If statements to validate user input
-Dictionaries to store information
-Lists to store cybersecurity tips 
-Methods containing separate validations for different inputs
-Imports for audio, generic collections and 
-Button so input can be read by the program


USAGE:

As soon as the program loads the user sees the screen with several questions that need user input the user will have textboxes whereby input is required for every invalid input an error message will display back to the user in red if valid then a pink font will lso display back to the user to indicate that the value has been detected and stored by the program. To be able to see those messages for every input the user would have to press the send button to be able to engage with the program.
